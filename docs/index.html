Concordance and robustness analysis for RNA-seq differential expression

DEConcord quantifies agreement between RNA-seq differential expression results obtained with different tools (DESeq2, edgeR, limma-voom), significance thresholds and sample subsets.

Install Source code

Python ≥ 3.9  |  MIT licence  |  Input: tables with gene identifier, log2 fold change and p-value

Overview

Differential expression results are commonly reported from a single analysis configuration. DESeq2, edgeR and limma-voom are based on different statistical models, and the set of genes called significant can differ between them on identical input. DEConcord takes result tables produced by these tools and reports the extent of agreement between them. It does not perform primary differential expression analysis in place of these tools.

Analyses

Method concordance

Jaccard index of significant gene sets, Pearson and Spearman correlation of log fold changes, directional agreement, and lists of concordant, discordant and method-specific genes.

Threshold sensitivity

Concordance metrics evaluated across a range of significance thresholds, identifying genes whose significance does not depend on the threshold chosen.

Pathway stability

Overlap of significantly enriched pathways between two enrichment tables derived from different differential expression results.

Resampling stability

Differential expression repeated on sample subsets (subsampling or leave-one-out), with per-gene replication rate, direction stability and rank stability.

Validation on public datasets

DESeq2, edgeR and limma-voom were each run with default settings on two public datasets: airway (human airway smooth muscle cells) and pasilla (Drosophila melanogaster). Pairwise concordance is shown below.

Jaccard: size of the intersection of the two significant gene sets divided by the size of their union. Fold-change r: Pearson correlation of log2 fold changes across all genes tested by both tools. Same direction: proportion of genes significant in both results with log2 fold changes of the same sign.

Summary. Differences between tools were confined mainly to genes near the significance threshold (Jaccard index 0.718 to 0.951). No gene was called significant by both tools of a pair with opposite direction of effect.

Concordance was further assessed on subsets of the Bottomly dataset under three conditions: unbalanced group sizes, a technical covariate (library size) with and without adjustment, and reduced sequencing depth (25% and 5% of reads). Unbalanced group sizes produced the largest reduction in agreement (DESeq2 vs edgeR Jaccard index 0.930 to 0.704). Directional agreement was 1.000 in all 24 comparisons. Usage

From Python

import pandas as pd
from deconcord.concordance.methods import compute_de_concordance

deseq2 = pd.read_csv("deseq2_results.csv", index_col="gene_id")
edger = pd.read_csv("edger_results.csv", index_col="gene_id")

result = compute_de_concordance(
    deseq2, edger, name_a="DESeq2", name_b="edgeR",
    lfc_col_a="log2FoldChange", pvalue_col_a="padj",
    lfc_col_b="logFC", pvalue_col_b="FDR",
)
result["summary"]["jaccard_index"]     # Jaccard index of significant genes
result["discordant_genes"]                # significant in both, opposite sign

From the command line

deconcord concordance deseq2_results.csv edger_results.csv \
    --name-a DESeq2 --name-b edgeR \
    --lfc-col-a log2FoldChange --pvalue-col-a padj \
    --lfc-col-b logFC --pvalue-col-b FDR \
    --out concordance_output

Output: summary.json, merged.csv (values from both tables for every compared gene) and separate CSV files for concordant, discordant and method-specific genes. A complete example is provided in examples/quickstart.py.

The package additionally contains a two-group analysis pipeline (input validation, sample QC, CPM normalisation, Welch and moderated t-tests, hypergeometric pathway enrichment, volcano and PCA plots), used to generate result tables for comparison. It is not intended as a replacement for DESeq2 or edgeR.

Limitations

  • Validation covers a small number of public datasets with two-group designs.
  • The built-in pipeline supports two-group comparisons, optionally with covariates. Paired designs and designs with more than two conditions are not supported.
  • Resampling stability uses subsampling and leave-one-out; bootstrap resampling is not implemented.
  • Pathway stability does not detect enrichment tables built from different gene-set collections or background sets.
  • All metrics are established measures (Jaccard index, correlation, directional agreement); no new statistical method is proposed.

Ongoing work

Evaluation on public Alzheimer's disease RNA-seq datasets, comparing the variation in differential expression results attributable to the choice of tool with that attributable to the choice of dataset.
