Concordance and robustness checks for RNA-seq differential expression

DEConcord compares differential expression results from DESeq2, edgeR, limma-voom or any other tool, and tells you which conclusions survive a reasonable change of method, significance cutoff or sample set.

Install Source code

Python 3.9+  |  MIT licence  |  works on any table with a gene ID, log fold change and p-value

Why compare tools?

Most RNA-seq studies report the genes that one tool, run once, called significant. DESeq2, edgeR and limma-voom make different statistical assumptions, and each is a reasonable choice. If a conclusion depends on which one you picked, that is worth knowing before building on it. DEConcord does not replace these tools: it takes their result tables and measures how far they agree.

What it checks

Method concordance

Overlap of significant genes between two result tables, fold-change correlation, direction agreement, and the exact genes behind every disagreement.

Threshold sensitivity

The same comparison across a range of significance cutoffs, to find genes that stay significant whatever reasonable cutoff you choose.

Pathway stability

Whether a pathway stays enriched when the gene list underneath it comes from a different tool.

Resampling stability

Reruns the analysis on subsets of samples (subsampling or leave-one-out) to see whether a gene's call depends on which samples were collected.

Results on public datasets

Each tool was run separately with its own default settings on two public datasets, airway (human airway smooth muscle cells) and pasilla (Drosophila), and every pair of tools was compared.

Jaccard: share of significant genes two tools have in common (1 = identical lists). Same direction: share of genes significant in both whose fold changes point the same way.

Main finding so far. The tools disagree about which borderline genes clear the significance cutoff, by up to about a quarter of the list. They never disagreed about direction: no gene was significantly up in one tool and significantly down in another.

A stress test on subsets of a third public dataset (Bottomly) pushed the comparison further: increasingly unbalanced groups, a technical covariate, and reads thinned to 25% and 5% of the original depth. Unbalanced groups reduced agreement the most (DESeq2 vs edgeR Jaccard fell from 0.93 to 0.70). Across all 24 comparisons, direction agreement stayed at 100%. Scripts and full tables are in benchmarks/.

Usage

From Python

import pandas as pd
from deconcord.concordance.methods import compute_de_concordance

deseq2 = pd.read_csv("deseq2_results.csv", index_col="gene_id")
edger = pd.read_csv("edger_results.csv", index_col="gene_id")

result = compute_de_concordance(
    deseq2, edger, name_a="DESeq2", name_b="edgeR",
    lfc_col_a="log2FoldChange", pvalue_col_a="padj",
    lfc_col_b="logFC", pvalue_col_b="FDR",
)
result["summary"]["jaccard_index"]     # overlap of significant genes
result["discordant_genes"]                # significant in both, opposite direction

From the command line

deconcord concordance deseq2_results.csv edger_results.csv \
    --name-a DESeq2 --name-b edgeR \
    --lfc-col-a log2FoldChange --pvalue-col-a padj \
    --lfc-col-b logFC --pvalue-col-b FDR \
    --out concordance_output

Output: summary.json, a merged table with both tools' values for every gene, and separate lists of concordant, discordant and tool-specific genes. A complete runnable example is in examples/quickstart.py.

The package also includes a small pipeline for producing result tables in the first place (input validation, sample QC, normalisation, two simple DE tests, pathway enrichment, volcano and PCA plots). It supports the comparisons; it is not meant to compete with DESeq2 or edgeR.

Limitations

  • Results so far come from a few public datasets with simple two-group designs.
  • The built-in pipeline handles two-group comparisons (optionally with covariates) only: no paired samples or designs with more than two conditions.
  • Resampling uses subsampling and leave-one-out, not a true bootstrap.
  • Pathway stability cannot detect when two enrichment tables were built from different gene-set collections.
  • The metrics are standard ones (Jaccard, correlation, direction agreement); no new statistical method is claimed.
